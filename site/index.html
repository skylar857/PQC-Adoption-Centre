Limitations

  • Percentages use reachable hosts as the denominator; unreachable and timed-out hosts are reported separately.
  • The Indian categories are small samples, so most differences between categories are not statistically significant.
  • This is server-side support at one moment from one vantage point (Chennai). It does not measure browser adoption.
  • Many sites inherit hybrid support from a CDN, so a hybrid result does not always mean the operator enabled it.
  • Only the key exchange is hybrid; certificates and signatures are still classical.
  • The Tranco list includes infrastructure domains that are not websites.
  • Handshake cost rows are estimates built from openssl speed in Docker on WSL2.
